# Arc Gym Website

## Overview

Arc Gym is a responsive fitness website developed as a web development project. The website allows users to explore gym services and register for membership plans through an online form. User registration details are stored in a MySQL database using PHP.

The project demonstrates frontend web development, backend integration, and database connectivity concepts.

---

## Features

* Responsive and modern user interface
* Gym membership registration form
* Multiple membership plan options
* Form validation
* Data storage using MySQL database
* PHP backend integration
* User-friendly design

---

## Database Functionality

When a user submits the registration form:

1. User enters personal details.
2. PHP collects form data.
3. Data is validated.
4. Information is stored in the MySQL database.
5. Successful submission message is displayed.
